## Проекты

### 1. [Аналитический дашборд сети видеопроката (Sakila DB)](./sakila_dashboard/)
* **Задача:** Проектирование архитектуры витрин данных (Data Marts) и создание интерактивного бизнес-дашборда для анализа операционных и финансовых показателей сети видеопроката.
* **Что сделано:** 
  * Разработан ETL-скрипт на Python/SQL для трансформации сырых операционных данных во взвешенные аналитические витрины (`vitrine.db`).
  * Реализованы продвинутые SQL-запросы с использованием оконных функций (`LAG`, `OVER`, `PARTITION BY`) и обобщенных табличных выражений (`WITH/CTE`) для расчета кумулятивной выручки, скользящего среднего (7-day rolling avg) и когортного анализа удержания клиентов.
  * Развернута инфраструктура BI-системы **Metabase** через **Docker Compose** с сохранением метаданных дашборда для воспроизводимости проекта.
* **Как запустить дашборд локально (за 10 секунд):**
  1. Перейдите в папку проекта: `cd sakila_dashboard`
  2. Запустите контейнер: `docker compose up -d`
  3. Откройте в браузере: `http://localhost:3000` *(Логин: admin@example.com / Пароль: admin1234)*
* **Ссылки:** 
  * [Скрипт трансформации данных (SQL)](./sakila_dashboard/sql/vitrine_creation.sql)
  * [Скрипт оркестрации пайплайна (Python)](./sakila_dashboard/run_etl.py)
