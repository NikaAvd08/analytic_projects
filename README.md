# analytic_projects

Репозиторий содержит решения практических задач и соревнований на платформе Kaggle. 

## Стек технологий и инструменты
* **Язык:** Python
* **Библиотеки:** Pandas, opendatasets, PIL
* **Инструменты:** Jupyter Notebook, Kaggle API

## Проекты

### 1. [what-on-the-video]
* **Задача:** Разбиение видеоряда на кадры, обработка их содержания и MLB классификация темы видео
* **Что сделано:** Создание класса для обработки видео, обучение модели классификации обработанных кадров 
  * [Код в репозитории](./video_label/video_label.ipynb)


### 2. [lamoda-images-classification]
* **Задача:** Бинарная классификация изображений
* **Что сделано:** Создание класса для изображений, обработка изображений, обучение модели классификации 
* **Ссылки:** 
  * [Код в репозитории](./lamoda/lamoda.ipynb)
 
### 3. [sakila]
* **Задача:** Создание дашборда на основе базы данных sakila
* **Что сделано:** Агрегация данных с использованием sql запросов, создание дашборда с помощью metabase
* **Ссылки:** 
  * [Код в репозитории](./lamoda/lamoda.ipynb)
