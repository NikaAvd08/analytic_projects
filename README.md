# analitic_projects

Репозиторий содержит мои решения практических задач и соревнований на платформе Kaggle. Проекты направлены на разведочный анализ данных (EDA), предобработку массивов информации и построение базовых моделей машинного обучения.

## Стек технологий и инструменты
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy (обработка данных), Matplotlib, Seaborn (визуализация) и тд
* **Инструменты:** Jupyter Notebook, Kaggle API
